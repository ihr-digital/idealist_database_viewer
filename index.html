Idealist database reader

Opens .TEX files from Blackwell's Idealist and turns them into searchable records. Files are read in your browser, and nothing is uploaded.

Open an Idealist database

Pick the database's .TEX file, which holds the records. Add its .DEF file to get the real field names. The CMH project's IDEALIST.DEF is built in, and any .DEF you load is remembered in this browser. The index files (.TRM, .OCC, .ROT, .DIR) aren't needed.

…optionally with a .DEF file, or use “Open files” above.
